## Matheus Agostinho

Olá! Sou desenvolvedor back-end brasileiro e trabalho com **Java e Spring Boot**, criando APIs REST que resolvem problemas reais do dia a dia de uma operação. Não busco o sistema perfeito: busco o sistema que funciona, é fácil de manter e conta a verdade sobre os dados.

Hoje construo uma API que centraliza os **processos de importação de painéis de LED** e rastreia a configuração técnica de cada lote: receiver, scan, firmware e arquivo `.rcfgx`. Ela liga o mundo do hardware ao software.
